# FPGA 개별 실습 · STM32_0 주차 (4비트 곱셈기 / BCD→이진수 변환)

이 폴더의 Verilog/SystemVerilog 소스는 `Glaysia/ece2_474` 저장소(태그 `v1.1.0`)의
`docs/FPGA_additional.md`에서 그대로 가져온 것이다. 임의로 작성하거나 추측한
코드가 아니라, 해당 문서에 실려 있는 "설계 모듈 콜아웃"과 "테스트벤치 콜아웃"을
그대로 옮겼다.

저장소 문서 자체에 실려 있는 검증 범위 안내(원문 그대로):
> 검증 범위: Icarus Verilog로 8개 테스트벤치가 모두 PASS했다. Vivado 합성·타이밍
> 확인이나 실제 보드 시연은 아직 수행하지 않았다.

이 세션에는 iverilog가 설치되어 있지 않아 내가 직접 재시뮬레이션해서 PASS를
다시 확인하지는 못했다 — 문서에 실린 코드를 한 글자도 바꾸지 않고 그대로 복사했을
뿐이다. 실제 PASS 확인은 본인 PC/보드의 Vivado(또는 iverilog)에서 직접 돌려봐야 한다.

## 폴더 구성

```
mult_4bit/
  mult_4bit.v          <- 보드에 올릴 최상위 모듈
  multiply_unsigned.v  <- 실제 곱셈을 수행하는 하위 모듈
  tb_mult_4bit.sv       <- 시뮬레이션 전용 테스트벤치 (보드 합성 시 제외)

bcd_conv/
  bcd_conv.v           <- 보드에 올릴 최상위 모듈
  bcd_to_binary.v      <- 변환+유효성 검사를 수행하는 하위 모듈
  tb_bcd_conv.sv        <- 시뮬레이션 전용 테스트벤치 (보드 합성 시 제외)
```

## 사용 방법

1. **시뮬레이션**: 각 폴더의 `.v` 설계 파일 전체 + `tb_*.sv`를 시뮬레이션
   프로젝트에 추가하고, 시뮬레이션 최상위를 `tb`로 지정해 실행한다.
   `PASS ...` 메시지가 뜨는지 확인한다. (두 실습 모두 모듈 이름이 `tb`로
   동일하므로, 한 번에 한 실습씩만 올린다.)
2. **보드 시연**: `tb_*.sv`를 빼고, 각 폴더의 설계 `.v` 파일만 합성 프로젝트에
   추가한다. 최상위 모듈은 `mult_4bit` 또는 `bcd_conv`다.

## 보드 핀(XDC)은 포함하지 않음 — 반드시 확인할 것

`FPGA_additional.md` 원문에 명시된 대로, **이 자료에는 XDC(핀 제약) 파일이
포함되어 있지 않다.** 저장소 문서 원문:
> 보드 핀은 교재와 장비 핀맵을 보고 연결한다. 이 자료에는 XDC를 포함하지
> 않았다. 버튼의 원시 신호를 한 번 누름 펄스로 만드는 처리는 기존 실습
> 코드를 연결한다.

즉 `clk_50mhz`/버튼/스위치/LED를 **Combo II-DLD S75 보드의 실제 핀**에
연결하는 XDC는 장비와 함께 제공된 교재에서 직접 확인해 작성해야 한다 —
이 저장소나 내가 추측해서 만들 수 있는 부분이 아니다. 참고로 이 두 실습은
클록이나 리셋 없이 순수 조합회로(`assign`)로만 되어 있어, 버튼 디바운스
같은 추가 처리 없이 입력 스위치/버튼을 그대로 연결해도 된다. 다만 정확한
핀 번호(어느 스위치가 `a`/`b`/`ten`/`one`인지, 어느 LED가 `m`/`bin`/`valid`인지)는
교재의 핀맵표를 보고 본인이 지정해야 한다.
